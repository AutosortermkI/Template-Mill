# API Setup Guide

## Etsy API
1. Go to https://www.etsy.com/developers/
2. Create a new app
3. Set OAuth redirect URI
4. Note API key and shared secret
5. Complete OAuth 2.0 PKCE flow to get access/refresh tokens

## Pinterest API
1. Go to https://developers.pinterest.com/
2. Create a business account
3. Create an app and request ads API access
4. Generate access token

## Gumroad API
1. Go to Gumroad Settings > Advanced
2. Generate an access token

## Shopify Admin API
1. In Shopify admin, go to Settings > Apps and sales channels
2. Develop apps > Create an app
3. Configure Admin API scopes (read/write products, orders)
4. Install app and note access token

## Anthropic API
1. Go to https://console.anthropic.com/
2. Create an API key
3. Set as ANTHROPIC_API_KEY in .env
