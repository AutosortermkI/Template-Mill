# Platform Guide

## Supported Platforms

### Etsy
- **API**: REST API v3 (OAuth 2.0)
- **Listing constraints**: Title max 140 chars, 13 tags max (20 chars each)
- **Digital products**: Set `is_digital=true`, `type="download"`
- **Fees**: 6.5% transaction fee + $0.20 listing fee

### Gumroad
- **API**: REST API v2
- **Pricing**: Flexible (pay-what-you-want supported)
- **Fees**: 10% flat fee

### Shopify
- **API**: Admin REST API + GraphQL
- **Digital delivery**: Requires app (Digital Downloads or Sky Pilot)
- **SEO**: Full control over meta title, description, URL handle

### Payhip
- **API**: None (manual listing management)
- **Fees**: 5% on free plan, 0% on Plus plan ($29/mo)

### Pinterest (Marketing)
- **API**: v5 (OAuth 2.0)
- **Pin specs**: 2:3 ratio (1000x1500px), first 50 chars of description most important
- **Board strategy**: Keyword-rich board names
